# Windows-Update-Assistant
A lightweight, efficient tool that takes the hassle out of keeping your Windows PC up‑to‑date. It automatically checks for and installs the latest updates for Windows, Microsoft Store apps, Office, and third‑party software – all from a single interface.
📖 Overview
Windows Update Assistant is a PowerShell‑based utility designed to simplify the update process on Windows 10 and 11. It eliminates the need to manually check multiple places for updates, saving you time and ensuring your system always has the latest security patches and features.

You can run it interactively for on‑demand updates, or set up a scheduled task to run it automatically – daily, weekly, or monthly – so you never fall behind.
